Enhanced Cookie Banner Test Page

This page is designed to test the enhanced cookie banner functionality. The banner should appear when you first visit the page (unless you've already given consent).

Test Controls

Cookie Banner Features to Test

  • Initial Banner: Should show on first visit with "Preferences", "Reject All", and "Accept All" buttons
  • Preferences Modal: Should open when clicking "Preferences" with expandable sections
  • Toggle Controls: Strictly necessary (always on), Performance, and Marketing toggles
  • Save Settings: Should save custom preferences and hide banner
  • Accept All: Should enable all cookies and hide banner
  • Reject All: Should only allow necessary cookies and hide banner
  • Persistence: Preferences should persist across page reloads
  • Responsive Design: Should work on mobile and desktop
