Python SDK Integration

A guide to integrating the tilli SDK in your Python environment to manage invoices, payments, and webhooks.

1

Installation

Install the official tilli Python SDK via pip:

bash
pip install tilli

Requires Python 3.7 or later.

2

Initialization

Import the SDK and initialize it with your API key:

bash
from tilli import tilliClient

client = tilliClient(api_key="your_api_key_here")

Use sandbox key for testing, or a live key for production.

3

Send Your First Invoice

Use the create_invoice() method to send a new invoice:

bash
invoice = client.invoices.create({
  "amount": 125.50,
    "currency": "USD",
    "customer_email": "customer@example.com",
    "due_date": "2025-06-01"
})
print(invoice.id)

Use sandbox key for testing, or a live key for production.

4
