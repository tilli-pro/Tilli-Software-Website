# New Blog Page - tilli Blog

## Overview
A completely redesigned blog page created based on the latest Figma design specifications. This new page features a modern, clean design with improved user experience and responsive layout.

## Features

### 🎨 Design Elements
- **Merged Hero & Articles Section**: Combined sections with geometric background for visual continuity
- **Left-Aligned Titles**: "tilli Blog" and "Articles" titles are left-aligned as per Figma design
- **Geometric Background**: Subtle geometric shape overlay for visual interest
- **Featured Post Carousel**: Showcases the latest blog post with image, title, description, and author info
- **Category Filters**: Interactive filter buttons for different blog categories
- **Search Functionality**: Search bar for finding specific articles
- **Articles Grid**: Two-column layout with featured article and side articles
- **Newsletter Subscription**: "Get Smarter About Finance" subscription section
- **Editor's Picks**: Horizontal carousel of recommended articles
- **Responsive Design**: Fully responsive across all device sizes

### 📱 Responsive Breakpoints
- **Desktop**: 1024px and above
- **Tablet**: 768px - 1023px
- **Mobile**: 480px - 767px
- **Small Mobile**: Below 480px

### 🎯 Key Sections

1. **Hero Section**
   - Large blog title

   - Author information and read time

2. **Articles Section**
   - Category filter buttons
   - Search functionality

3. **Newsletter Section**
